# Bank logo assets

Official brand marks for Indian banks shown in Paisa's You / account list.

## Source / licensing

SVGs and the Slice PNG are official (or official-derived) brand marks bundled
for on-device display of the user's own accounts. They are **not** AI-generated
or geometric placeholders.
